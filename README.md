# FastLoot

Мгновенный сбор добычи для **World of Warcraft: Forever** (Interface 16001).

Стандартный автосбор забирает вещи по одной, пока рисуется окно добычи. FastLoot забирает всё сразу по событию `LOOT_READY`, ещё до появления окна.

Работает по тем же правилам, что и автосбор игры: автосбор включён (Esc → Options → Controls → Auto Loot) и модификатор не зажат, или автосбор выключен и зажата клавиша автосбора (по умолчанию Shift). Иначе открывается обычное окно.

Что нельзя забрать (сумки полны, розыгрыш Need/Greed, подтверждение «персональный предмет»), остаётся в окне как обычно.

| Команда | Что делает |
|---|---|
| `/fastloot` | включить/выключить |

Установка: `./install.sh`, потом `/reload` (новый аддон: выйти на экран выбора персонажа и зайти снова). Тесты: `lua tests/fastloot_test.lua`.
